Data / New York City jails

How many people are in NYC jails today?

On October 31, 2026, 6,647 people were in the custody of the New York City Department of Correction (6,124 male, 512 female, 11 not recorded).

Source: Daily Inmates In Custody, published by the NYC Department of Correction. The agency last updated it on 2026-10-30. Case Analytica read it on 2026-10-31. The file shows one day only and leaves out sealed cases.

Is this the Rikers Island population?

Not exactly. The file counts everyone in the Department of Correction's custody. It has no field for the facility where a person is held, so Case Analytica does not publish a count for Rikers Island alone. For the Rikers questions the file cannot answer, see the articles at the bottom of this page.

Why this number can differ from other reports

The agency says the file leaves out sealed cases and that totals built from it "may differ slightly from other published statistics." This is also one day's count, read on October 31, 2026. An average over a month will not match a single day.

Daily history

The agency's file holds only the current day. Case Analytica saves each day it reads the file. The record starts on October 31, 2026 and grows each time this page is refreshed.
