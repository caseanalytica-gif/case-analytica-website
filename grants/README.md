# EEC parole pilot: funding plan

Working folder for the EEC / parole-denial pilot grants. Everything here is a `.md` file, so the
Pages deploy skips it and none of it is served.

| File | What it is |
| --- | --- |
| `concept-note.md` | One-page concept note. The base text for every application and the Sills inquiry. |
| `budgets.md` | A $5,000 rapid budget and a $40,000 one-year budget. Every line is an estimate to check. |
| `north-star-rapid-response.md` | Draft answers for North Star Fund Rapid Response. |
| `aj-muste-rapid-response.md` | Draft answers for A.J. Muste Rapid Response. |

Source list: `caseanalytica_eecc_parole_pilot_grants_1.pdf` (CA AI folder). Checked against the
web on 2026-10-13. The funders' own sites were unreachable from the cloud session, so several
points below come from search results and third-party listings. Each one says so.
